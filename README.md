Legend Mendonca | Tech for Tomorrow

A personal portfolio website showcasing my interests in technology, science, programming, and creative projects.

Built with HTML and CSS, the website features a custom embedded Minecraft Ten font and a responsive layout designed for modern devices.

Features

- Custom typography using an embedded font.
- HTML and CSS-based website structure.
- Responsive viewport configuration for mobile devices.
- Personalized branding and presentation.

Technologies

- HTML5
- CSS3
- Embedded Base64 font data

Purpose

This project represents my interest in technology, creativity, and building things for the future.
